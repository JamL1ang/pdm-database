## 二、为什么 SQL 源码不用改

Navicat 和 Workbench 都是**客户端（遥控器）**，真正执行 SQL 的是 **MySQL 服务端 8.0.16+**。`CHECK` 约束、`CREATE ROLE`、视图不能含派生表、联合主键、复合外键……这些全由服务端版本决定，跟用哪个图形界面无关。

变的只有「怎么把 `.sql` 灌进去」：

| 想做的事 | Navicat Premium 17 | MySQL Workbench |
| --- | --- | --- |
| 执行整个 .sql 文件 | 右键连接 → **运行 SQL 文件…**（编码 UTF-8）→ 开始 | File → Open SQL Script → ⚡⚡ Execute All |
| 写一句 SQL 自己跑 | 查询 → 新建查询 → ▶ 运行 | 双击连接 → Ctrl+T → ⚡ 单闪电 |
| 看结果 / 报错 | 下方「结果」「信息」标签 | 下方 Result Grid / Output |

> 注意：老师这份 Navicat 是**绿色免安装版**，它不含 MySQL 服务端。本机**实测已装 MySQL Server 8.0.46 且服务正在运行**，直接连 `127.0.0.1:3306` 即可；若换到没装服务端的电脑，仍需装 MySQL 8 或连机房服务器（向老师要主机 / 端口 / 账号 / 密码）。
