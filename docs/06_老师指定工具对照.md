## 二、为什么 SQL 源码不用改

Navicat 和 Workbench 都是**客户端（遥控器）**，真正执行 SQL 的是 **MySQL 服务端 8.0.16+**。`CHECK` 约束、`CREATE ROLE`、视图不能含派生表、联合主键、复合外键……这些全由服务端版本决定，跟用哪个图形界面无关。

变的只有「怎么把 `.sql` 灌进去」：

| 想做的事 | MySQL Workbench（本次使用） | Navicat Premium 17（可选） |
| --- | --- | --- |
| 打开连接 | 首页双击 `Local instance MySQL80` | 双击左侧连接树 |
| 执行整个 .sql 文件 | File → Open SQL Script → ⚡⚡ Execute All | 右键连接 → 运行 SQL 文件…（UTF-8）→ 开始 |
| 写一句 SQL 自己跑 | Ctrl+T 新建标签 → ⚡ 单闪电 | 查询 → 新建查询 → ▶ 运行 |
| 看结果 / 报错 | 下方 Result Grid / Action Output | 下方「结果」「信息」标签 |

> 本机**实测已装 MySQL Server 8.0.46 且服务 `MySQL80` 正在运行**，`3306` 已监听，版本满足 `CHECK` / `CREATE ROLE` 所需的 8.0.16+，**服务端不用再装**。老师那份 Navicat 是绿色免安装版，本身不含服务端；若换到没装 MySQL 的电脑，仍需装 MySQL 8 或连机房服务器（向老师要主机 / 端口 / 账号 / 密码）。
