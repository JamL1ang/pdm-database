# 数据字典（schema.sql v2，共 18 张表）

类型以 MySQL 8.x 为准。PK = 主键，FK = 外键，UQ = 唯一，NN = 非空，CK = CHECK。

## 一、产品与文档

### product_type 产品类型
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| type_id | INT | PK | 类型编号 |
| type_name | VARCHAR(50) | NN, UQ | 手机 / 无人机 / 扫地机 |

### product 产品（型号）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| product_id | INT | PK | 型号编号 |
| type_id | INT | NN, FK→product_type | 所属类型 |
| series | VARCHAR(50) | | 系列 |
| model | VARCHAR(100) | | 型号规格 |
| price | DECIMAL(12,2) | | 价格 |

### product_version 产品迭代版本
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| version_id | INT | PK | 版本编号 |
| product_id | INT | NN, FK→product | 所属型号 |
| version_no | VARCHAR(20) | NN, UQ(product_id, version_no) | v1.0 / v1.1 |
| release_date | DATE | | 版本发布日期 |
| change_note | VARCHAR(200) | | 改版说明 |

### document 设计文档
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| doc_id | INT | PK | 文档编号 |
| version_id | INT | NN, FK→product_version | **挂在版本上，不是产品上** |
| doc_type | VARCHAR(20) | NN | 设计说明书 / 设计图 / CAD文件 |
| doc_rev | VARCHAR(20) | NN | 文档自身修订号 |
| title | VARCHAR(200) | | 标题 |
| file_path | VARCHAR(500) | | 文件路径 |
| author | VARCHAR(50) | | 作者 |
| update_date | DATE | | 更新日期 |

UQ(version_id, doc_type, doc_rev)：同一版本下同类文档同修订号只能有一份。

## 二、部件与 BOM

### component 部件
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| component_id | INT | PK | 部件编号 |
| component_code | VARCHAR(50) | NN, UQ | 部件编码 |
| component_name | VARCHAR(100) | NN | 外壳 / 显示屏 / 主板 … |
| source_type | CHAR(4) | NN, CK IN('采购','自产') | 来源途径 |

### material 材料
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| material_id | INT | PK | 材料编号 |
| material_code | VARCHAR(50) | NN, UQ | 材料编码 |
| material_name | VARCHAR(100) | NN | 接头 / 连接线 / PCB板 / 芯片 |

### product_component 产品—部件 BOM
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| product_id | INT | PK 之一, FK→product | 型号 |
| component_id | INT | PK 之一, FK→component | 部件 |
| quantity | INT | NN | 单台用量 |

### component_material 自产部件—材料 BOM
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| component_id | INT | PK 之一, FK→component | 自产部件 |
| material_id | INT | PK 之一, FK→material | 材料 |
| quantity | DECIMAL(12,4) | NN | 用量 |

## 三、供应商

### supplier 供应商
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| supplier_id | INT | PK | 供应商编号 |
| supplier_name | VARCHAR(100) | NN | 名称 |
| contact | VARCHAR(50) | | 联系人 |
| phone | VARCHAR(20) | | 电话 |
| address | VARCHAR(200) | | 地址 |

### component_supplier 部件可供清单
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| component_id | INT | PK 之一, FK→component | 采购部件 |
| supplier_id | INT | PK 之一, FK→supplier | 可供供应商 |
| supply_price | DECIMAL(12,2) | | 报价 |

### material_supplier 材料可供清单
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| material_id | INT | PK 之一, FK→material | 材料 |
| supplier_id | INT | PK 之一, FK→supplier | 可供供应商 |
| supply_price | DECIMAL(12,2) | | 报价 |

> 自产部件（主板、接线）不出现在这两张表：它们不采购成品，来源由材料层体现。

## 四、批次与追溯（核心）

### batch 生产批次
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| batch_id | INT | PK | 批次编号 |
| batch_no | VARCHAR(50) | NN, UQ | 批次号 |
| product_id | INT | NN, FK→product | 本批生产的型号 |
| production_date | DATE | | 生产日期 |

### product_instance 单台产品
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| serial_no | VARCHAR(50) | PK | **唯一出厂序列号** |
| product_id | INT | NN, FK→product | 型号 |
| batch_id | INT | NN, FK→batch | 所属批次，供货源由此继承 |
| production_date | DATE | | 出厂日期 |

### batch_component_source 批次部件供货源
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| batch_id | INT | PK 之一, FK→batch | 批次 |
| component_id | INT | PK 之一, 复合FK→component_supplier | 部件 |
| supplier_id | INT | NN, 复合FK→component_supplier | 该批次实际供应商 |

### batch_material_source 批次材料供货源
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| batch_id | INT | PK 之一, FK→batch | 批次 |
| material_id | INT | PK 之一, 复合FK→material_supplier | 材料 |
| supplier_id | INT | NN, 复合FK→material_supplier | 该批次实际供应商 |

> `PRIMARY KEY(batch_id, 物料id)` 是题目第 8 条「同一批产品供货源相同」的落地：一个批次里每种物料只允许一家供应商。

## 五、权限（扩展）

### sys_role 角色
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| role_id | INT | PK | 角色编号 |
| role_name | VARCHAR(30) | NN, UQ | 设计工程师 / 采购员 / 质检员 |

### sys_user 用户
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| user_id | INT | PK | 用户编号 |
| username | VARCHAR(50) | NN, UQ | 登录名 |
| role_id | INT | NN, FK→sys_role | 所属角色 |

### doc_permission 文档权限
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| role_id | INT | PK 之一, FK→sys_role | 角色 |
| doc_type | VARCHAR(20) | PK 之一 | 文档类型 |
| can_read | TINYINT | NN, 默认 0 | 可读 |
| can_write | TINYINT | NN, 默认 0 | 可写 |
