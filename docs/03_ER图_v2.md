## 关系读法

- `product }o--o{ component` 这类 M:N 在图上**拆成两张 1:N**：`product → product_component ← component`。所有 M:N 都通过中间表实现，中间表带业务属性（`quantity` / `supply_price`）。
- 两张 `batch_*_source` 是本题关键：它们同时连 `batch` 和「可供清单」，用复合外键保证批次指定的供应商确实登记过。
- 权限三表是独立的一组，与产品主流程解耦。

## 三条主链路

1. **设计文档**：`product → product_version → document`
2. **供应商统计**：`supplier → component_supplier / material_supplier`（能供什么），以及 `batch → batch_*_source → supplier`（实际用了谁）
3. **缺陷溯源**：`product_instance.serial_no → batch → batch_*_source → supplier`，物料清单由 `product_component` 与 `component_material` 两层 BOM 展开得到
